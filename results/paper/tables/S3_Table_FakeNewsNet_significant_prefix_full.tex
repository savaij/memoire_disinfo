{\large\bfseries S3 Table. Using the first few tweets or all recovered tweets on FakeNewsNet.}\par\medskip
Each row compares the same model using either the first $k$ recovered tweets or all recovered tweets for a story. Twenty of the 120 comparisons remain significant after the Holm correction. Fourteen predict engagement above the 75th percentile, four above the 90th and two above the 95th. No differences remain significant for fake/real labels or the median engagement cutoff. $\Delta$F1 is the mean score using the first $k$ tweets minus the score using all tweets. Every value is negative: using all tweets gives a higher F1 in every row. Cliff\textquotesingle s $\delta$ follows the same direction. The $p$-values are adjusted across 24 comparisons for each task and cutoff: six models, each tested with four values of $k$.\par\smallskip
Scores come from ten runs, using the same data splits for both models or text windows in each comparison. In each run, the classification threshold was chosen on a separate calibration set. Only differences with a Holm-adjusted $p<0.05$ are shown. The adjustment includes all comparisons in each group, including those not shown here. The 95\% confidence intervals account approximately for overlap between the data splits; they are not adjusted for multiple comparisons. Cliff's $\delta$ describes how the scores differ across runs; it is not a separate significance test. In the model names, \texttt{bert} means RoBERTa embeddings and \texttt{mistral} means Mistral embeddings.\par\medskip
